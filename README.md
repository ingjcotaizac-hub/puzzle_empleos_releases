## ¿Por qué Android muestra un aviso de seguridad? (No es un virus)

Cuando descargas cualquier aplicación Android directamente desde una web en lugar de usar Google Play Store, el propio sistema Android muestra por defecto mensajes preventivos como:

- *"Es posible que el archivo sea dañino"* (al descargar un archivo `.apk` desde el navegador).
- *"Por seguridad, tu teléfono no puede instalar aplicaciones desconocidas desde esta fuente"* (al abrirlo por primera vez).

Ese aviso aparece de forma automática para **todo archivo `.apk`** instalado fuera de Google Play, incluso cuando es software legítimo y oficial. No significa que el archivo contenga virus ni código malicioso.

## Cómo instalar en Android (4 pasos)

1. Pulsa el enlace oficial de descarga de **`puzzle-empleos.apk`** y espera a que termine.
2. Abre el archivo descargado desde las notificaciones o desde la app **Descargas / Archivos** de tu teléfono.
3. Si Android te lo solicita, entra en **Configuración** y activa **«Permitir desde esta fuente»** para tu navegador o gestor de archivos.
4. Pulsa **Instalar**. Cuando termine, puedes volver a desactivar ese permiso si lo prefieres.
